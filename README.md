# darkostack

Small, tested skills for working with AI coding agents, by [@harishdarko](https://www.linkedin.com/in/harishdarko).
Each skill is a few plain Markdown files you can hand to Claude Code, Codex, Gemini or any other agent.

| Skill | What it does |
|---|---|
| [Promise Review](promise-review/) | Write down what must never break, check the spec, build test-first against it, then have a fresh reviewer prove every bug with a failing test. Scored 19/20 in a blind-graded experiment, ahead of a 3-agent team; the lite version with a pre-build spec check beat plain lite 9.5 to 8.5 on a held-out task. |

More skills will be added as they are tested. Licence: [MIT](LICENSE).
